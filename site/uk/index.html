Hata — це «хата»

Домашній сервер в одному файлі.

Вебпанель, магазин Docker-застосунків, файли, HTTPS і резервні копії. Старий ПК, міні-ПК чи Raspberry Pi стає домашнім сервером, яким ви керуєте з браузера.

curl -fsSL https://raw.githubusercontent.com/sanyadez/hata/main/install.sh | sudo sh

Одна команда для встановлення, далі все в браузері. Linux із systemd, x86_64 або arm64. Рання стадія розробки.

Що вона робить

Застосунки й усе інше, що потрібно домашньому серверу

Застосунки

Оберіть у магазині Jellyfin, Nextcloud, Home Assistant, Pi-hole чи ще понад сотню інших, натисніть «Встановити», і застосунок запрацює в Docker. Або вставте будь-який compose-файл.

Файли й спільні теки

Файловий менеджер у браузері й теки, спільні в мережі.

Резервні копії

Відновлюйте весь застосунок чи окремі файли. Тримайте другу копію деінде, а знімок перед кожним оновленням дасть скасувати невдале.

Диски та їх захист

Стан кожного диска й те, чим він заповнений. Один диск може тримати парність для решти, тож вміст диска, що вийшов з ладу, можна обчислити назад.

Користувачі й доступ

Родина відкриває свої застосунки й нічого більше. Запрошення за посиланням, двофакторний вхід, ключі доступу.

Помічник, який спершу питає

Запитайте своїми словами, чому не працює застосунок чи чим заповнений диск. Дивиться він одразу, а кожна зміна чекає на ваше «Виконати». Модель обираєте ви: API провайдера, для якого маєте ключ, або модель на власній машині. Агенти під’єднуються через MCP, із ключем одного з трьох рівнів.

Мережа

Інтерфейси й адреси, Wi-Fi, USB-модем як запасний шлях до інтернету, точка доступу. Якщо нова адреса відріже сервер, попередня повернеться сама.

Імена й HTTPS

hata.local та ім’я для кожного застосунку, без налаштувань на телефонах і роутері. HTTPS через ваш проксі або від Let’s Encrypt самою Hata.

Більше за один комп’ютер

Вона дбає й про решту дому

Інші комп’ютери під’єднуються через невеликий клієнт, без відкриття портів. Усе в одному дереві.

Сервери: усе в одному дереві.

Контейнери й віртуальні машини

Створюються на самому сервері, зі своїми лімітами й місцем зберігання. Віртуальні машини поки що тестова функція.

Proxmox VE

Гості сервера Proxmox: живлення, знімки, копії й те, що потребує уваги.

Інтеграції

Сервіси, що у вас уже працюють: пристрої Home Assistant, торенти qBittorrent, камери Frigate просто на Головній. У них нічого не встановлюється.

DNS із блокуванням реклами

Вимкнений, доки ви його не ввімкнете. Відповідає на імена дому, блокує за обраними списками й діє на телевізорах та в застосунках, куди не дістане жодне розширення браузера.

Чому так

Нічого, що не можна побачити чи прибрати

Один файл

Один процес, один двійковий файл, без мікросервісів і сервера бази даних поруч. Не операційна система: ставиться на ваш наявний Linux і так само легко прибирається.

Жодних залежностей

Побудована на Bun, без пакетів npm.

Застосунок — це compose-файл

Звичайний файл на диску, який запуститься й без Hata. Редагуйте текстом або формою.

Docker не ховається

Живі журнали, оболонка в контейнері, образи й томи з їхнім розміром. Те, що вже працює на машині, можна взяти як застосунки.

Як почати

Три кроки, після першого все в браузері

  1. Виконайте команду

    Вона завантажує двійковий файл останнього випуску, звіряє контрольні суми, встановлює Docker, якщо його немає, і запускає сервіс.

  2. Створіть адміністратора

    Наприкінці скрипт друкує адресу. Стандартних паролів немає, а для налаштування потрібен код, який показує лише консоль сервера.

  3. Оберіть перші застосунки

    Перший запуск проведе через назву сервера, те, що вже працює, місце для даних і копій та кілька застосунків для початку.

curl -fsSL https://raw.githubusercontent.com/sanyadez/hata/main/install.sh | sudo sh

Потрібна машина з Linux і systemd, x86_64 або arm64. Docker поставить скрипт, якщо його немає.
